QA Café Workforce Management System

This demonstration application provides a simple REST API for managing employee records. It has been created as part of the Software Engineering & DevOps module.

Current functionality
  • View all employees
  • Add a new employee
  • SQLite database storage
  • Flask REST API

Available Endpoints

Method Endpoint Description
GET /employees Returns all employee records as JSON.
POST /employees Adds a new employee to the database.

Example Employee JSON

{
    "name": "Matt Jones",
    "start_date": "2026-07-03",
    "location": "Cardiff",
    "role": "Tutor"
}
